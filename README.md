# Portal de inventarios de Tacna Ai

### Introduccion:

Los datos de inventarios en **Tacna Ai** tiene el proposito de estar indexados dentro de este sitio web desarrollado inicialmente en 2023 para poder llevar un manejo adecuado dentro del departamento de **IT** aunque actualmente funja en la empresa como la plataforma estandar para compartir esta información de parte del equipo de producción.

### Funciones:

Las funciones principales de la plataforma es facilitar los datos de inventario, pedidos y reportes de material en la empresa con el enfoque de poder ser vizualizados y tratados por el equipo de **IT**, asi que su desarrollo a continuado con el enfoque de manejar cada vez una cantidad de datos de forma mas confiable y actualizada posible entre los departamentos.

### Funcionamiento y Tecnologías:

Front-End:
- HTML (Ejecutado por PHP)
- Bootstrap 4

Back-End:
- PHP Vanilla
- JGraph

Servidor:
- 000WebHostApp

Actualmente la plataforma se encuentra en una transición de tecnologias en todos los niveles con el objetivo de terminar con estas tecnologías:

Front-End:
- HTML (Ejecutado por PHP)
- CSS
- JavaScript

Back-End:
- PHP Vanilla
- Google Charts
- Express

Servidor:

- 000WebHostApp
- Hostinger

### Estado actual:

La plataforma actualmente se encuentra alojada [aquí](https://tacnatest.000webhostapp.com) en su versión 1.0.0 desde Noviembre del 2023 aún sin un sitio web de pruebas en construccion.
